# fastforks: fast vision models for ComfyUI

Fast: the same models run up to 29x faster than the popular nodes, with 1.3x to 10x less peak VRAM (RTX 5060 Ti, warm
runs: Metric3D v2 normals 29x vs comfyui_controlnet_aux, Depth Anything V2 6x vs kijai/ComfyUI-DepthAnythingV2,
BiRefNet 3.6x vs ComfyUI-RMBG, Real-ESRGAN 3.6x vs ComfyUI's own upscale node). One node per task with a model
dropdown, weights download automatically, and it runs on Windows, Linux and macOS.

Tasks: depth and video depth, surface normals, background removal / matting, segmentation (SAM, SAM 2.1, SAM 3,
CLIPSeg), video segmentation (SAM 2 / SAMURAI), object detection (open-vocabulary too), pose (body, wholebody, hands,
faces), frame interpolation, classification, tagging (WD tagger), NSFW check, semantic segmentation, clothes / face
parsing, stereo disparity, optical flow and warping, point tracking, upscaling / restoration, face restoration.

> **Licences.** This pack has every fastforks model. Some are for non-commercial / research use only (their code or
> weights licence; GPL code: its copyleft terms): their dropdown entries are tagged `[non-commercial]`, and installing
> this pack is your opt-in to download their weights. Using each model within its licence is your responsibility
> (`fastforks info MODEL` shows the licences). For commercial work, install
> [fastforks-commercial](../comfyui-commercial) instead: the same nodes with only the models cleared for commercial use.

Install with ComfyUI-Manager or `comfy node install fastforks`; from a fastforks clone see
[docs/comfyui.md](../../docs/comfyui.md#install). On Apple silicon the requirements include Apple's `mlx`, which
the `auto` and `mlx` backends use. The node reference (inputs, outputs, backends) is
[docs/comfyui.md](../../docs/comfyui.md).
