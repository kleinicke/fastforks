# Earlier candidate license audit (2026-11-10)

This is the handoff audit preserved as historical evidence, not the current implementation queue.
On 2026-11-11 Florian approved assuming the original code license for weights when no separate
weight terms are stated, and explicitly accepted timm Apache-2.0 declarations for EfficientFormer
and EfficientFormerV2. Consequently, historical “unclear” or “do not start” conclusions based only
on an absent separate weight statement no longer block research. Explicit restrictive weight
terms still take precedence. New task contracts and third-party components still need technical
review. Current priorities and newer evidence are in [model-landscape.md](model-landscape.md).

# Licence checks (2026-11-10)

Method: `gh api repos/<o>/<r>/license`, LICENSE files, READMEs, release asset lists, HF API `cardData.license` and raw HF READMEs. "Yes" = code AND weights both commercial-OK as far as stated at the source. "Statement" = an explicit weights-licence sentence exists; if only the repo licence applies and the weights sit inside the repo / its releases, that is said explicitly. Training data is a note only.

## Clean and cheap to port next (clean licences, PyTorch weights, plain convs / ViT blocks)

Rank 1 = cleanest evidence and cheapest.

1. **TinyViT** (timm `tiny_vit_*`, Apache-2.0 cards; arch already in timm): plain conv + windowed-attention ViT.
2. **SHViT** (MIT code, timm card MIT, official weights in GitHub release): single-head ViT, plain ops.
3. **StarNet** (Apache-2.0 code and card): plain convs + element-wise star op, tiny.
4. **EfficientFormer / V2** (timm Apache-2.0 cards): plain ops (note official code/weights licence is the Snap MIT-style grant; use the timm weights).
5. **HGNetV2** (timm Apache-2.0 cards): conv backbone.
6. **MaxViT / CoAtNet** (timm Apache-2.0 cards): conv + attention, moderate (relative-position tables, grid attention).
7. **Real-ESRGAN (RRDBNet)** (BSD-3 code, weights are release assets of the same repo; no separate weights statement; SR training data note) and **SwinIR** (Apache-2.0, release assets): plain convs / Swin blocks.
8. **TEED** (MIT, 58K-param conv net, weights in-repo) and **TransNetV2** (MIT, weights in-repo, tiny dilated 3D convs; TF weights need the existing pytorch converter).
9. **Practical-RIFE** (MIT code AND explicit MIT statement for weights; convs + warping/grid_sample).
10. **DeepLSD** (MIT code AND explicit MIT weights statement; UNet), **AnyCalib** (Apache-2.0 card, DINOv2 ViT), **GeoCalib** (Apache-2.0, weights in release), **Cutie** (MIT, release assets), **EfficientSAM** (Apache-2.0, in-repo weights; SA-1B training-data note), **Lite Any Stereo V2** (MIT card).

Not clean (do not start): Franca (research-only weights); NAFNet, Restormer, SPAN, DINO-DETR, FC-CLIP, CAT-Seg, DexiNed, RIFE ECCV2022 (code OK but weights only on Google Drive / Space with no statement: unclear); LLMDet (licences clean at top level but built from several third-party components not verified; LLM-based).
